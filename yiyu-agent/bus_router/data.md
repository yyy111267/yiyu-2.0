# 数据可得性清单（Data Availability Manifest）

> 这份清单在 ReAct 循环**开始之前**注入模型上下文。
> 目的：让模型在思考"我要什么数据"之前，就知道**有什么、没什么、什么要用代理指标**。
> 这一步能消掉约 80% 的"取不到数就卡住/瞎编"问题——模型看到某项标 ✗，就不会去要它，而会自动转向代理指标或定性论证。

标记含义：
- ✓ **direct** — akshare 直接可取，可当真值用
- ~ **derive** — 需用底层字段推导（引擎已封装，可当真值用）
- △ **proxy** — 无法直取，用代理指标近似，**报告中必须标注"以 XX 近似"**
- ✗ **unavailable** — 数据源无此项，转文本检索或定性论证
- ▢ **text** — 不在数据表里，但年报/公告全文里有，需检索

## 一、财务基本面（框架第2、7步）

| 数据项 | 可得性 | 说明 |
|---|---|---|
| 营收/净利/毛利率/净利率 5-10年序列 | ✓ direct | 财务摘要接口 |
| ROE/ROA/资产周转率/负债率 | ✓ direct | 财务指标接口 |
| 三大报表全字段 | ✓ direct | sina 三表接口 |
| 经营现金流 / 自由现金流 | ~ derive | FCF = 经营现金流 − 资本开支 |
| 经营杠杆 | ~ derive | EBIT增速 / 营收增速 |
| TTM 口径（滚动12月） | ~ derive | 单季差分后累加，引擎处理 |
| 单季数据 | ~ derive | ★A股财报是累计数，Q3单季=三季报−中报，引擎已差分 |
| 分产品/分区域收入拆分 | ▢ text | 仅年报"主营构成"披露，半年度常缺 |
| 维持性 capex | △ proxy | 以折旧摊销近似（巴菲特本人亦如此） |

## 二、估值（框架第7步）

| 数据项 | 可得性 | 说明 |
|---|---|---|
| 当前股价 / 总市值 / 总股本 | ✓ direct | |
| PE(TTM/静) / PB / PS / 市现率 历史序列 | ✓ direct | 估值接口返回全历史 |
| PE/PB 历史分位 | ~ derive | 取全历史序列自算分位 |
| EPS(TTM) | ~ derive | 归母净利TTM / 总股本 |

| 三情景估值 | ~ compute | 固定kernel，假设值由模型提供并受历史分位约束 |
| 同行估值对比 | ~ derive | 需先确定可比公司集合 |

| 数据项 | 可得性 | 说明 |
|---|---|---|
| 股东户数变化 | ✓ direct | 筹码集中度参考 |
| 十大股东 / 机构持仓 | ✓ direct | |

## 四、框架里"天然无数据"的部分（第3/4/6步主体）

这些**不是数据缺失，而是本就该用论证而非取数**。模型不应尝试"取数"，而应走证据链论证：

| 框架要点 | 处理方式 |
|---|---|
| 护城河：能否不掉销量地提价 | 检索历史提价事件→量价拆分近似→管理层表述→竞品跟随情况 |
| 转换成本多高 | 定性：产品耦合度、数据沉淀、认证周期（如车规级） |
| 网络效应真伪 | 定性：用户增加是否让存量用户体验变好 |
| 失败路径 / 空方论点 | 文本检索：研报、雪球、做空报告 |
| TAM / 文明趋势 | 研报 + 定性，且须区分"潜在市场"与"可货币化市场" |

## 五、A股普遍取不到、需代理或第三方的项

| 想要的指标 | 代理方案（△ proxy） |
|---|---|
| MAU/DAU、用户数 | 年报披露值（▢ text）或第三方（QuestMobile）；多数A股无 |
| CAC 获客成本 | 销售费用 / 新增用户数（粗略，标 proxy） |
| LTV/CAC、NDR | SaaS 少数披露；否则无法可靠计算，转定性判断留存 |
| 产能利用率 | 产量/设计产能（▢ 年报）或固定资产周转率（△ proxy） |
| 良率 | 毛利率变化 + 存货跌价准备（△ proxy，仅方向性） |
| 单店模型/坪效 | 营收/门店数（▢ 年报披露门店数时可算） |
| 客户集中度 | 前五大客户占比（▢ 年报"重大客户"章节） |

## 六、取不到数时的降级阶梯（模型必须遵守的顺序）

模型遇到"想要的数取不到"，**严格按此顺序降级，绝不允许跳到"编一个数"**：

1. **换来源/换口径** — 备用数据源重试，标记 `source_degraded`
2. **用底层字段推导** — 多数"取不到"是"要得太高层"，要绝对值自己算
3. **用代理指标** — 见第五节，必须标注"以 XX 近似(proxy)"
4. **从年报/公告文本检索** — ▢ 标记项走这里，很多"没有"其实在文本里
5. **标记不可得，转定性论证** — 用证据链代替数字，标注证据强度
6. **影响结论时降低信心度** — 在第8步备忘录的"信心度"列显式体现，并写入"数据限制"

### 铁律
> 模型可以说"取不到，我用 X 近似 / 改用定性 / 降低信心度"，
> **但绝对不能自己填一个不存在的数字。**
> 治理层会把输出里的每个数字比对已取数据集，对不上直接打回重写。

### 信心度与数据完整度挂钩（对应框架第8步）
- 关键指标全部 ✓/~ → 信心度可为"高"
- 关键指标依赖 △ proxy → 信心度最高"中"，并注明代理来源
- 关键指标 ✗ 且影响结论 → 信心度"低"，结论须注明"待数据补充后复核"
