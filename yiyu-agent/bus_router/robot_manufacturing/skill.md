# robot_manufacturing · 机器人与高端制造 · 解读手册

> **适用范围**：工业机器人整机、核心零部件（减速器/伺服电机/控制器）、精密制造设备、新能源制造设备。
> **禁用场景**：纯软件/算法公司（无硬件主业）；消费品牌；强周期大宗原材料。
> **来源**：从 G6 高端制造迁移 + 机器人专属内容（2026-08-24）。
> **配合使用**：指标字典 v1.0；Core Skill（7维母框架，固定加载）。

---

## 一、这门生意靠什么赚钱

**一句话本质**：用技术积累的精密制造能力向下游收溢价——护城河来自工艺壁垒+客户验证成本，但强烈依赖下游资本开支周期。

**价值链位置的重要性**：

| 位置 | 代表 | 利润特征 | 研究重点 |
|------|------|---------|---------|
| 整机（工业机器人） | 埃斯顿/汇川 | 集成溢价，受整机竞争格局影响 | 市占率变化、单价年降幅 |
| 核心零部件（减速器/伺服） | 绿的谐波/禾川科技 | 技术壁垒最强，毛利率最高 | 国产替代份额、客户认证进度 |
| 精密制造设备 | 各类专机厂商 | 定制化强，客户粘性高 | 订单能见度、下游景气度 |

**核心判断**：公司在价值链哪个位置，决定了护城河来源——零部件 > 整机 > 系统集成。

## 二、产能利用率是毛利率的第一解释变量

与 semiconductor 相同的逻辑，机器人与高端制造也是**重资产、折旧刚性**：

- 折旧不因开机率下降而减少
- 产能空置 → 折旧摊薄不充分 → 毛利率急剧下滑
- 产能满载 → 折旧被充分分摊 → 毛利率好看

**分析禁忌**：孤立看毛利率是否同比下滑，不看产能利用率 → 得出错误结论。正确做法：先问「产能利用率在哪」，再解读毛利率变化。

## 三、两个利润美化红旗（与 semiconductor 相同，机器人行业同样高发）

**红旗一：折旧年限拉长**
- 设备本该 8 年折完，改成 12 年 → 每年少计折旧 → 利润虚高
- 与同业对比折旧年限，超出 2 年以上需警惕
- 配合：`depreciation_to_revenue` 下降 + 净利润增长 = 需要深究

**红旗二：研发资本化比例过高**
- 将本应费用化的研发计入资产，虚高利润
- 检验：机器人行业研发资本化比例通常 < 20%，超出须与同业对比

**两个红旗同时出现 = 结论降级，估值须做利润还原。**

## 四、国产替代：机器人的核心研究主线

**三阶段判断框架**（不能混淆）：

```
阶段1 技术验证：有没有能用的东西？
  证据：送样测试结果、技术参数对比、实验室数据
  ≠ 商业化成功

阶段2 小批量导入：客户在不在真实用？
  证据：首批订单金额、客户名单（是否一线大厂）、应用场景
  关键问题：是战略性小量采购还是真实商业化需求？

阶段3 量产放量：份额稳不稳？
  证据：市占率持续上升、客户复购、追加订单
  才能说「国产替代受益」
```

**需要额外追问**：
- 技术追赶速度 vs 外资迭代速度——如果外资每年进步 15%，国内进步 10%，差距在扩大
- 单价年降压力——大客户（汽车厂/3C）年度谈价 cost-down 幅度有多大？毛利率能否守住？

## 五、关键红旗

| 红旗 | 触发条件 | 含义 |
|------|---------|------|
| **周期下行** | book-to-bill < 1 且连续两期下滑 + 产能利用率 < 70% | 需求端恶化，利润下行压力大 |
| **份额流失** | 国产替代份额停止增长 + 外资品牌重新夺回份额 | 技术追赶失败，护城河伪命题 |
| **利润美化** | 折旧年限拉长 + 研发资本化比例高于同业（双重出现）| 利润数字不可信 |
| **单价崩塌** | 单价年降幅度 > 15% + 毛利率持续恶化 | 不具备对大客户的议价能力，长期价值毁损 |
| **技术代际颠覆** | 下游从传统工业机器人向协作/移动机器人大规模切换 | 老产品线被淘汰，新产品线尚未建立 |

## 六、推理顺序

```
1. book-to-bill + 订单能见度月数
   → 需求端景气度，判断顺/逆周期

2. 产能利用率
   → 解释当前毛利率，判断周期位置

3. 两个利润美化红旗（折旧年限 + 研发资本化）
   → 利润数字可信度

4. 国产替代进展（哪个阶段？份额增速？）
   → 护城河真实性

5. 客户集中度 + 单价年降幅
   → 下行风险边界

6. 周期调整估值
```

## 七、下游景气度的传导链

机器人需求强烈依赖下游资本开支，主要下游：
- **汽车（新能源）**：最大需求方，新能源车型切换带来焊接/装配自动化需求
- **3C 电子**：景气波动大，周期性明显
- **通用制造**（食品/医药/仓储物流）：增量方向，单笔订单小但持续性好

研究时必须判断：**下游资本开支周期当前处于哪个阶段**——下游收缩 capex 时，机器人需求会提前 1-2 季度反应。

## 八、估值

**成熟盈利公司**：

| 方法 | 适用场景 | 注意事项 |
|------|---------|---------|
| EV/EBITDA | 折旧政策差异大、跨公司对比 | 最可比，剔除折旧影响 |
| 正常化 PE | 周期调整（用中周期利润，非单年）| 禁止用周期顶部低 PE 做买入理由 |
| PB | 下行期/亏损期，净资产是底部锚 | 重资产公司适用 |

**早期/高增长公司**（规模尚未达稳态）：
- PS（`ps_ttm`）/ EV/Revenue（`ev_revenue`）
- 重点看收入增速是否在加速或减速

**周期特别提醒**：
- 禁止在产能利用率高峰期（毛利率最好看时）用单年 PE 做买入理由
- 下行期「便宜」往往是陷阱，因为利润会继续下滑

## 九、指标优先级（配合指标字典 v1.0）

> `★` = 本行业最优先

**必算**：
- `★` book-to-bill 订单出货比（赛道指标，公告取数）
- `★` 产能利用率（赛道指标）
- `★` 折旧占收入比（赛道指标，监控利润美化）
- ROIC（`roic`）——精密制造公司 ROIC 是技术壁垒的证明
- 毛利率 + 趋势（`gross_margin`）——配合产能利用率解读
- EV/EBITDA（`ev_ebitda`）

**结合情况算**：
- 研发资本化比例（赛道指标，年报附注）
- 客户集中度（赛道指标，年报附注）
- 资本开支强度（`capex_intensity`）——扩产节奏是否合理
- 固定资产周转率（赛道指标）

**本行业禁用**：
- 单年 PE 外推（强周期，顶部 PE 低而底部 PE 高）
- 孤立看毛利率（必须配合产能利用率）

---

## 十、输出契约

- 结论前说清楚「当前周期位置」+ 「国产替代阶段」
- 两个利润美化红旗是否已查，结论里明确说明
- 国产替代进展必须标注当前所处阶段（技术验证/小批量/放量），不得笼统描述
- 估值选择说明理由（为什么不用 PE、用什么代替）
- 结尾：证伪条件 + 跟踪指标（关注 book-to-bill、产能利用率、单价年降趋势）
