# 研究报告前端优化交接清单

> 范围：只处理页面展示、交互和视觉，不修改 Agent、研究计划、工具路由、提示词或结论规则。
> 后端负责提供最终正文、结构化引用和研究状态；前端不得自行推断研究结论。

## P0：影响当前可用性的简单修复

- [ ] 最终回答使用已安装的 `marked + DOMPurify` 安全渲染 Markdown，不再用 `textContent` 直接显示正文。
- [ ] 支持标题、加粗、列表、引用、分隔线和 Markdown 表格；确认页面不再出现裸 `##`、`**`、`---`。
- [ ] 流式阶段可以先显示纯文本；收到 `final_answer` 后，以服务端完整正文重新做一次安全 Markdown 渲染。
- [ ] 研究正文使用独立 `.research-report` 容器，不复用普通聊天气泡的窄版式。
- [ ] 桌面端正文可读宽度调整到 820～960px；有来源侧栏时整体内容区允许扩展到 1280～1440px。
- [ ] 移动端标题、表格、长链接和来源卡片不得横向撑破页面；表格允许容器内横向滚动。
- [ ] 禁止展示 `P0/P1/P2`、`data_requirement`、工具名、工具参数、内部 JSON 和内部错误栈；后端漏发时前端也要做显示层兜底过滤。
- [ ] 完成态只保留“分析完成 · 查看过程”，默认折叠研究进度。

## P1：研究报告页面结构

- [ ] 报告顶部增加标的标题、证券代码、数据截止日期、研究耗时和数据状态。
- [ ] 第一屏提供“核心判断卡”：投资倾向、生意质量、护城河趋势、估值状态、最大不确定性。
- [ ] 为正文标题生成页内目录，滚动时高亮当前章节；移动端目录折叠。
- [ ] 对【事实】、【估算】、【判断】使用克制的标签样式，不使用大面积高饱和色。
- [ ] 数据缺失、推断和降级输出使用统一提示组件，不散落内联红字。
- [ ] 报告末尾增加操作区：复制、重新研究、针对本报告追问、赞/踩。
- [ ] “认知陪练”使用单独卡片，突出一个关键分歧和一个反思问题，不与正文列表混排。

## P1：来源与溯源交互

- [ ] 支持 `final_answer.metadata.citations[]` 的结构化渲染，不显示 `market_get_bundle` 等内部工具名。
- [ ] 正文中的 `[e1]` 等引用显示成上标引用按钮；点击后打开右侧来源抽屉并定位对应来源。
- [ ] 来源卡展示：标题、来源类型、发布日期/数据期、字段口径、URL、证据等级。
- [ ] 同一来源去重；一个结论引用多个来源时支持展开查看。
- [ ] 桌面端来源抽屉宽 360～420px；移动端改为底部抽屉。
- [ ] URL 缺失时显示“结构化行情/计算结果”等用户可理解的来源类型，不回退为内部工具名。

## P2：视觉与体验完善

- [ ] 优化字号、行高、段落间距、表格密度和深色模式对比度。
- [ ] 长报告首次进入时定位到报告顶部，不强制持续滚动到底部；用户主动向上阅读时暂停自动滚动。
- [ ] 为来源抽屉、折叠进度、页内目录补键盘操作和无障碍标签。
- [ ] 为加载、超时、降级、无来源、来源加载失败分别设计稳定状态。
- [ ] 添加桌面 1440px、桌面 1920px、平板和手机四档截图回归。

## 后端接口依赖

前端实现来源抽屉前，需要后端在 `final_answer.metadata` 稳定提供：

```json
{
  "citations": [
    {
      "evidence_id": "e1",
      "title": "来源标题",
      "url": "https://...",
      "source_type": "company_filing|market_data|calculation|news|research",
      "as_of": "2026-08-28",
      "period": "2025FY",
      "field": "revenue",
      "caliber": "公司年报口径",
      "source_level": "S|A|B"
    }
  ]
}
```

接口字段不齐时，前端先完成 Markdown、版式和折叠进度，来源抽屉不要用假数据占位。

## 前端验收标准

1. “分析茅台”页面不出现裸 Markdown 和内部研究术语。
2. 1920px 宽屏上正文不缩成中间窄条，也不出现大面积无意义留白。
3. 所有正文引用都能打开来源；没有 URL 的证据也能说明来源类型和数据期。
4. 长报告的章节层次、表格和风险提示在桌面与手机均可读。
5. 前端只负责表达，不改变后端结论正文和引用关系。
