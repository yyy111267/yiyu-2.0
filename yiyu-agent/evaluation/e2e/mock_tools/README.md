# 端到端假工具（mock_tools）

> 产品经理视角：评测时我们不希望 AI 真去拉实时股价、真去联网搜索——
> 那样又慢又贵，而且题目结果会变，考试就没法复现、没法对比「这次是不是比上次好」。
>
> 这里放「假的行情」和「假的搜索」，让同一道题每次跑结果都一样。

## 当前状态
- 端到端评测目前复用上层的 `evaluation/mock_tools/preloop_mocks.py` 作为假数据来源。
- 若后续端到端需要独立的假行情/假搜索回放，可在此目录补充 fixture 文件。

## 约定的子目录
- `fixtures/` —— 固定的行情快照、搜索结果样本等测试数据。
