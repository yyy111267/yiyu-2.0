# 报告质量评分标准（rubric）

> 产品经理视角：这是「什么算一份好报告」的评分细则。满分 100，用来给 `e2e/datasets/quality/` 的考卷打分。
> 当前评分逻辑实现在 `e2e/scripts/quality.py`，本文件是给人工和 AI 判卷员共同参照的标准说明。

## 维度与权重（建议）

| 维度 | 权重 | 判卷关注 |
|---|---|---|
| 结论明确性 | 25 | 有没有一句话说清「值不值得」 |
| 来源可信度 | 25 | 关键数字是否标注真实来源，无编造 |
| 风险揭示 | 20 | 是否提示主要风险点 |
| 逻辑连贯 | 15 | 论据是否支撑结论，无跳步 |
| 表达清晰 | 15 | 结构、排版是否易读 |

## 红线（一票否决）
- 编造数据或伪造来源 → 0 分。
- 遗漏用户明确要求的必答项 → 0 分。

> 注：本 rubric 为初版框架，后续可抽成 YAML 供 `e2e/scripts/` 直接读取，减少代码与文档脱节。
