# 端到端能力地图（e2e/skills）

> 说明：端到端考卷测的是「成品体验」，不是单道工序。
> 这里列出 `e2e/datasets/` 里每摞考卷，分别代表了用户视角的哪类任务。

| 考卷目录 | 代表用户任务 | 验收关注点 |
|---|---|---|
| `benchmark/` | 标准研究委托（如「研究某上市公司投资价值」） | 结论对不对、来源真不真、风险提没提 |
| `quality/` | 同一类任务，但更抠「写得咋样」 | 有没有明确结论、逻辑通不通、排版清不清楚 |
| `smoke/` | 随便来个简单问题 | 5 秒内确认主链路没挂 |
| `regression/` | 历史上出过问题的场景 | 老 bug 有没有被改回来 |

每道具体题目的内容见 `../datasets/` 下对应的 YAML 文件。
