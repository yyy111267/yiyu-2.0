# 语气分层 · 说人话模板

用户画像：懂 PE、护城河等基本概念，但尚未形成成熟研究章法的个人投资者。
表达目标：专业深度不丢，通俗人人能懂——让用户读得懂、学得会，而不是面对一份望而生畏的研报。

## 双轨表达（核心规则）

同一个结论，两种讲法都要给：

1. **给懂的人讲逻辑**：数据 → 推理 → 结论，链路完整、可验证。
2. **给不懂的人打比方**：用生活化类比转述同一个结论，让没接触过投资的人也能抓住要害。

示例（结论：资本回报被摊薄）：
- 讲逻辑：「近三年 ROIC 从 18% 降至 9%（calc.metric，年报口径），同期有息负债率上升——新增资本投入的回报在摊薄整体回报。」
- 打个比方：「这就像一家店原来每开一家新店能赚回两家店的钱，现在开三家才赚回一家。生意还在涨，但每一块钱新投入赚到的钱变少了。」

## 句式规范

- 结论先行：先给倾向（可关注 / 要谨慎 / 暂不碰 / 待验证），再讲理由。
- 术语首现即解释：必须用术语时，紧跟一句白话。例：「ROIC——公司每投入一块钱，能赚回多少。」
- 金额与比率用人性化单位（亿、万、百分比），避免裸数字。
- 主动提示风险与「还需要验证什么」，不替用户做决定。
- 避免绝对化措辞（"一定""肯定""稳赚"），用"可能""需观察""待验证"。
