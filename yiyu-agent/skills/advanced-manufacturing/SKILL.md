# 高端制造价值投资能力

本包不把“机器人”代表整个高端制造。先确定子类型与价值链，再用行业证据回答通用价值投资问题。

## 先分子类型

- **机器人/自动化**：整机、核心零部件和系统集成分开；关注性能、稳定性、渠道、服务与集成人力。
- **专用设备**：关注下游资本开支、可执行订单、交付、验收、客户复购与服务。
- **精密零部件**：关注工艺、良率、认证、平台寿命、份额、单价年降与材料成本。
- **汽车整车**：关注品牌/产品定义、车型周期、销量与价格、渠道、软件/服务、产能和质保责任。
- **汽车零部件**：区分定点、定点对应车型量产、单车价值量、年降、客户集中和平台生命周期。

## 按价值投资母框架研究

1. **生意本质**：公司售卖标准产品、工程能力、产能、项目交付还是全生命周期服务？收入在出货、验收或服务时确认？
2. **长期需求与结构**：将结构性渗透、下游扩产、库存周期、车型/技术更替和政策需求分开。
3. **护城河**：用良率、质量一致性、客户认证、平台寿命、份额、服务网络和成本曲线验证，不把技术参数或送样当成护城河。
4. **管理层与资本配置**：检查扩产纪律、并购、负债、研发项目选择和新品类扩张是否获得超过资本成本的回报。
5. **财务质量**：检查订单到收入、收入到现金的转化，以及应收、合同资产、存货、质保、折旧和研发资本化。
6. **成长与再投资**：区分份额、单车/单机价值量、价格、产品结构、新产能和并购；核对增量 ROIC 而不只看收入。
7. **估值与安全边际**：成熟制造用正常化盈利/FCF 或 EV/EBITDA；重资产下行期辅以 PB；整车需单独检查价格战、产能和软件/服务假设。
8. **证伪与跟踪**：定点/送样不转量产、订单不转验收现金、年降超过降本、良率/质保恶化或扩产回报不足均会证伪价值假设。
