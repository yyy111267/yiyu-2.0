# 消费品牌价值投资能力

本包在通用价值投资母框架下，用消费行为、品牌、渠道和品类证据验证长期价值；指标计算交给 `metric-calculation`。

## 按价值投资母框架研究

1. **生意本质**：客户买的是功能、信任、身份、便利还是礼赠/社交价值？复购来自真实消费还是渠道备货？
2. **长期需求与结构**：区分品类扩容、消费升级/降级、份额转移、短期流量和礼赠需求；检查品牌、渠道和平台的议价权。
3. **护城河**：提价或结构升级必须经过销量、份额、复购或终端动销验证；高毛利率不单独证明品牌强。
4. **管理层与资本配置**：评估长期品牌/渠道投入、新品牌孵化、并购、跨界投资、回购和分红是否增加每股价值。
5. **财务质量**：结合 ROIC、FCF、营运资本、渠道条款、退货/折扣和库存语义，判断品牌价值是否真正转化为现金。
6. **成长与再投资**：将销量、提价、产品结构、新渠道、新品类和并购分开，检查增量投入回报而不只看收入增长。
7. **估值与安全边际**：使用正常化 PE、FCF/DCF 或反推 DCF，将价格、销量、份额、利润率与再投资假设分开；不使用固定 PE 或折价阈值。
8. **证伪与跟踪**：提价后份额/复购下降、终端动销弱于出货、渠道库存与退货上升、新品类长期回报不足都会证伪品牌价值假设。

库存先分熟成资产、安全库存、临期风险和时尚过季；合同负债只适用于相关预付款渠道模式。
