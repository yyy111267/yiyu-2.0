# 半导体与算力硬件价值投资能力

先分 Fabless、IDM/Foundry、封测、存储和算力硬件；它们的资本强度、周期证据和估值逻辑不同。

## 按价值投资母框架研究

1. **生意本质**：公司售卖 IP/芯片、晶圆产能、封测服务、存储商品还是算力系统？利润受产品、价格、良率、稼动率还是供应制约驱动？
2. **长期需求与结构**：将终端需求、公司出货、客户/渠道库存和价格分开；不把补库存当成结构性需求。
3. **护城河**：用 IP、工艺、良率、设计生态、客户认证、软硬协同和量产份额验证；技术参数或送样不等于商业护城河。
4. **管理层与资本配置**：评估技术路线选择、研发组合、扩产时点、并购和供应链投入是否获得超过资本成本的回报。
5. **财务质量**：检查库存与减值、折旧年限、研发资本化、政府补助、客户集中和供应承诺；会计政策用历史与同类子类型比较。
6. **成长与再投资**：区分市场扩张、份额、涨价、产品升级和并表；对新制程/产能使用中周期增量 ROIC 而不是顶部利润。
7. **估值与安全边际**：制造/封测用中周期 EV/EBITDA 和 PB，成熟 Fabless 用正常化现金盈利，早期未盈利硬件才用 PS/EV-Revenue 反推稳态回报。
8. **证伪与跟踪**：认证不转量产、技术路线被客户放弃、库存/价格恶化、良率不改善、扩产回报不足或关键供应受限会证伪价值假设。

产能利用率只对自有制造直接适用；Fabless 使用库存、交期、订单和代工/封装供应证据。
