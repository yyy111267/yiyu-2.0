# 通用价值投资能力

研究的目标不是罗列行业信息，而是判断一项生意的长期现金创造能力与当前价格之间的关系。行业能力包只改变证据、口径和证伪方式，不改变下列母框架。

## 价值投资判断链

1. **生意本质与能力圈**：客户为什么付费，谁获得价值，公司靠什么获利，收入与现金如何转化？无法解释收入、成本和价值链时，明确标记超出能力圈。
2. **长期需求与行业结构**：需求是结构性还是周期性，价值链利润如何分配，供给、竞争和监管会如何改变回报？
3. **护城河及其持久性**：区分品牌、成本、网络、切换成本、工艺/IP、渠道、规模和监管特许。护城河必须同时有客户行为和经济回报证据。
4. **管理层、激励与资本配置**：评估诚信、能力、激励和历史决策；检查再投资、并购、负债、回购、分红和稀释是否增加每股价值。
5. **财务质量与真实盈利**：把会计利润还原为经济利润，检查现金转化、营运资本、股权激励、资本化、折旧、负债和表外承诺。
6. **成长空间与再投资回报**：区分行业增长、份额增长、提价、产品结构和并购；核对增量资本回报与可持续再投资空间。
7. **正常化价值与安全边际**：先估计中周期/稳态现金创造能力，再选择 DCF、反推 DCF、正常化盈利或资产价值。报告市场隐含假设，不输出伪精确目标价。
8. **风险、证伪与跟踪**：对每个核心判断写明反方证据、失效条件和可观测跟踪指标。管理层口号、行业叙事和单一指标不能独立完成验证。

## 证据到结论

每个重要结论均按“价值问题 → 可溯源证据 → 判断 → 反证/证伪 → 对长期价值和安全边际的影响”组织。数据不足时保留问题，不用行业均值或故事补齐。
