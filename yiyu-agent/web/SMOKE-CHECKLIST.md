# 前端冒烟用例与异常状态检查（MVP 收口）

> 视角：测试/产品。目标：确认第一版「公司研究 + 我的认知 + 历史研究 + 设置」这条主闭环在真实后端下能完整走通，且异常态用户可理解、有明确下一步。
> 不重复后端 `evaluation/e2e` 评测体系；本清单只覆盖**用户可点击的路径**与**可见状态**。

## 一、主闭环（必须全绿）

1. **登录**
   - [ ] 未登录刷新页面直接进入访客主页，不出现全屏登录门禁。
   - [ ] 未登录时发起研究 → 弹出邮箱验证码登录，不白屏。
   - [ ] 登录成功后自动回到原研究意图并继续。
   - [ ] 取消登录后，聊天输入框保留原草稿，且不出现伪造的用户消息或加载气泡。
   - [ ] 侧边栏底部「登录」与「我的认知」的访客拦截均打开同一个登录弹窗。

2. **发起公司研究**
   - [ ] 侧边栏「公司研究」→ 进入对话页。
   - [ ] 输入「研究贵州茅台的护城河」→ 出现思考过程（计划/调用工具/结论）。
   - [ ] 研究计划面板展示 P0 问题清单。

3. **确认认知**
   - [ ] 研究结束出现「沉淀认知」卡片。
   - [ ] 点确认 → 卡片状态变为已确认；网络失败时有错误态与重试。

4. **进入认知库**
   - [ ] 侧边栏「我的认知」→ 列表含刚确认的认知（来自真实后端 `/api/v1/memory`，非 mock）。
   - [ ] 刷新页面后认知仍在（已落库）。

5. **再次研究（认知被引用）**
   - [ ] 新会话研究同公司 → 思考过程或结论中出现「基于你的认知：…」待验证问题/引用。

6. **历史研究**
   - [ ] 侧边栏「历史研究」→ 列表来自真实 `/api/v1/sessions`（非 mock 假历史）。
   - [ ] 列表标题 = 首次提问的清洗截断结果（如「贵州茅台护城河与增长空间」），不再是「研究会话」。
   - [ ] 点击历史项 → **回放该会话的用户提问与研究报告**，页面不再同时出现欢迎页。
   - [ ] 重复点击当前已打开的那一条也能重新加载（不能只依赖 hash 变化）。
   - [ ] 同一会话继续提问 → 消息追加到该会话，不覆盖上一轮，侧边栏标题不变。
   - [ ] 点「新对话」→ 不带上一会话 id，开启全新会话。
   - [ ] 提示文案是「正在查看历史对话」，不是「已恢复上下文」（上下文续聊见 TODO-frontend 4.6）。

## 二、异常状态（用户必须可理解、有下一步）

7. **加载态**：研究进行中显示思考进度与打字态，不卡死。
8. **取数/工具失败**：某工具 ✗ 时后续有降级结论或明确失败提示，不出现假完成。
9. **网络错误**：断网发起研究 → 失败卡片含「重新研究」按钮，可重试。
10. **空数据/降级**：结论标明「部分数据缺失/降级」，不展示空报告伪装成功。
11. **空状态**：认知库为空时显示引导文案；历史为空时显示「还没有历史研究」。
12. **未授权**：token 失效 → 401 弹登录，不静默失败。

## 三、边界确认（不要伪装已上线）

13. **导航收口**：主导航只出现 公司研究 / 我的认知 / 历史研究 / 设置；持仓追踪、交易复盘无任何可点击入口。
14. **认知库数据闭环**：列表/确认/编辑/删除均走真实后端接口协议（协议由另一个 AI 统一定义），不读写 localStorage mock。
15. **会话隔离**：A 账号的历史项，换 B 账号直接请求 `GET /api/v1/sessions/{id}` 返回 404，侧边栏也不出现。

## 验收结论

- 1~6 全绿 = 主闭环打通。
- 7~12 异常态均有明确提示与下一步 = 不出现「页面完成、实际没写后端 / 假完成」。
- 13~14 = 收口到位，不暴露半成品。
